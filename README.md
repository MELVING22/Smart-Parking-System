# Smart Parking System

An automated solution for vehicle detection, gate access, and parking slot allocation using embedded tech.

---

## 🔧 Technologies Used

- Embedded C
- Arduino Nano
- IR Sensors
- LED Indicators

---

## 🚗 Problem Statement

Manual parking systems at malls and complexes lead to delays, confusion, and inefficient space use.

---

## 💡 Solution

Built a microcontroller-based system that detects vehicles at the entrance, opens the gate, and guides drivers to available slots using LED indicators.

---

## 🧰 Key Features

- IR sensor at entry triggers gate
- Real-time slot monitoring via IR sensors
- Guided parking path with lights
- Auto exit suggestion if parking is full

---

## ✅ Outcome

The prototype automated vehicle intake and improved space utilization. Successfully demonstrated in a simulated environment with zero human intervention.
